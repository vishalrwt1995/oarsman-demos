Demo build, no client

Drop your CSV, get a KPI dashboard

Drop in a sales, orders or finance export and get headline numbers, monthly trends, a breakdown by category and channel, and targets with red, amber and green flags. You can download it all as an Excel file. Your file is read in this tab and never uploaded.

What's real and what isn't
  • RealThe CSV parser, column detection, sums, margins, month-on-month change, target flags, charts and the Excel export all run in your browser. Check the network tab: nothing is sent after the page loads.
  • SampleThe sample file is fictional store data (1,551 orders, Nov 2025 to Oct 2026) that we generated for this demo. It isn't any business's real numbers.
  • AI useAI tools helped write the code and copy. A person at Oarsman AI checked it, and it's covered by unit tests and browser tests. Chart.js (MIT) draws the charts, and SheetJS (Apache 2.0) writes the Excel file.
